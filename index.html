Módulo 1

Módulo 1: Arquitectura y Estructura de Computadores

La arquitectura de computadores explica cómo el sistema interpreta instrucciones, organiza datos y coordina la ejecución de tareas mediante unidades funcionales.

ALU

ALU – Unidad Aritmético-Lógica

Realiza operaciones aritméticas y lógicas básicas sobre datos.

  • Concepto: unidad de cálculo elemental.
  • Función: ejecutar operaciones binarias.
  • Importancia: procesa instrucciones y datos.
UC

UC – Unidad de Control

Coordina el flujo de instrucciones y señales del sistema.

  • Concepto: director del ciclo de ejecución.
  • Función: interpretar y sincronizar instrucciones.
  • Importancia: organiza Fetch, Decode y Execute.
REG

Registros

Almacenan datos temporales y direcciones de trabajo interno.

  • Concepto: almacenamiento interno de alta velocidad.
  • Función: guardar operandos e instrucciones.
  • Importancia: reduce tiempo de acceso al procesador.

Módulo 2

Módulo 2: Fundamentos de Redes de Comunicaciones

Una red de comunicaciones permite la conexión entre dispositivos para compartir recursos, transportar datos y sostener servicios digitales.

◇

Concepto

Una red es un conjunto de dispositivos interconectados que intercambian información mediante reglas y medios de transmisión.

↔

Comunicación

Las redes permiten que ordenadores, servidores, accesos inalámbricos y servicios compartan datos de forma organizada.

✓

Importancia

La conectividad estructura infraestructuras modernas, validaciones, acceso remoto y sistemas de información.

Componentes de una red

Componentes de una red

▦

Computadores

Equipos finales que generan, procesan y consumen información.

Concepto: nodos de origen y destino.
▩

Servidores

Dispositivos que ofrecen servicios, datos y recursos a la red.

Concepto: prestación centralizada.
✧

Switches

Conectan equipos locales y gestionan tráfico dentro de la LAN.

Concepto: conmutación local de datos.
✤

Routers

Dirigen paquetes entre redes y permiten el acceso entre dominios.

Concepto: encaminamiento inter-red.
⎯

Medios de transmisión

Cablas, radio y fibra transportan señales electromagnéticas.

Concepto: soporte físico o inalámbrico.
✺

Puntos de acceso

Extienden conectividad inalámbrica en una infraestructura.

Concepto: acceso inalámbrico a redes.
●

Dispositivos finales

Teléfonos, impresoras, sensores y equipos de usuario.

Concepto: consumidores y emisores de datos.
Direcciones

Dirección IP vs Dirección MAC

Dirección IP

La IP identifica un nodo dentro de una red lógica y se usa para conducir paquetes entre redes.

Ejemplo: 192.168.1.10
Dirección MAC

La MAC identifica la interfaz física de un equipo dentro de una red local.

Ejemplo: AA:BB:CC:DD:EE:FF

Topología en estrella

Todos los dispositivos se conectan a un concentrador o switch central, simplificando gestión y solución de fallos.

  • Funcionamiento: dispositivos enlazados a un nodo central.
  • Ventajas: fácil administración y aislamiento de fallos.
  • Desventajas: dependencia del nodo central.
Módulo 3

Módulo 3: Aplicación en la Investigación de Ciberdelitos

El conocimiento técnico de computadores y redes es esencial para estructurar un análisis de evidencia digital responsable.

¿Por qué es fundamental el conocimiento de RAM, registros y tráfico de red?

Durante una investigación, la memoria RAM puede contener procesos activos, conexiones, credenciales temporales, datos de memoria y artefactos volátiles. Los registros y eventos del sistema ayudan a reconstruir secuencias temporales de actividad. El tráfico de red revela comunicaciones y patrones de comportamiento que pueden asociarse con acciones sospechosas.

RAM

RAM

La memoria volátil conserva procesos activos, datos temporales y conexiones que pueden desaparecer al apagar el equipo.

REGISTROS

Registros

Los registros del sistema y aplicaciones permiten reconstruir eventos, intención, actividad y secuencia de operaciones.

TRÁFICO

Tráfico de red

El análisis del tráfico identifica conectividad, patrones, comunicaciones y datos que apoyan una investigación.

Análisis forense digital

Importancia del análisis forense digital

Dispositivo → Adquisición de información → Análisis → Interpretación → Obtención de evidencia → Informe

El análisis debe respetar procedimientos técnicos, garantizar la integridad de la evidencia y evitar alteraciones indebidas.

Conclusiones

Conclusiones

Comprender la arquitectura de computadores, la CPU, la jerarquía de memoria, las redes, IP y MAC, la topología, la RAM, los registros y el tráfico de red permite explicar el funcionamiento de los sistemas tecnológicos y fundamentar investigaciones de ciberdelitos con rigor técnico.
